How FundFlow works

FundFlow reviews every campaign before donors ever see it. Here's the path a campaign takes, and how donating actually works underneath.

Campaign verification

1
Draft

Organizer writes up the campaign.

2
Pending

Submitted for admin review.

3
Approved

Live and visible to donors.

—
Rejected / Blocked

Sent back with admin notes, or removed if suspicious.

Donating

This is a demo project, so payments run through a mock payment flow — no real money moves. You pick an amount and a mock payment method, and the system returns Success, Failed, or Pending, the same way a real gateway would. Every attempt is recorded as a transaction so you can see exactly what happened.

Notifications

Every account has an in-app notification bell — donation results, campaign approvals, new donations received, and more, all inside FundFlow. No email or SMS.
